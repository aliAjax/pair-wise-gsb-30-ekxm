# 油品应急保供调度台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原"油品配送计划"记单功能上补成应急保供调度台，数据保存在浏览器 localStorage 中。

## 业务规则

1. **油站登记**：登记备用库存、所需油品与缺口，支持特急 / 加急 / 常规三级优先级（附停电、道路封闭等现场备注）。
2. **按优先级分配**：调度员从「待发车」计划中按吨数切额度，也可一键自动分配（特急优先、同级按登记时间，贪心匹配）。
3. **在途不占用**：已发车（运输中）、已到站的计划不再进入可分配池，不占用可分配额度。
4. **同车同时段单趟**：同一车辆在同一日期 + 上午/下午/夜间时段只能排一趟。
5. **退回写明缺口**：油品不符、车辆载重不足、无可用计划时退回并留痕，写明缺口吨数。
6. **送达核减释放**：确认实际送达后，油站备用库存增加、缺口自动核减，占用额度释放回计划。
7. **超时回收**：占用超过 24 小时未确认送达，启动时（或刷新后）自动回收，额度回到待分配。
8. **调度动态**：分配、退回、送达、释放、超时回收全程日志留痕，替代群消息拼库存。
