# 油品应急保供调度台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

停电、道路封闭等突发情况下的应急保供调度闭环（数据保存在浏览器 localStorage）：

1. **油站登记**：登记备用库存、保供所需油量、缺口（= 所需 − 备用）、保供优先级与突发情况。
2. **分配调度**：调度员可一键按优先级（一级紧急优先、同级先登记先配）从「待发车」且有额度的可用配送计划中分配，也可手工指派；油品不符、车辆载重不足会直接退回并写明缺口，同一车辆同一时段只接一趟。
3. **额度规则**：已发车（运输中）、已到站的油量不再占用可分配额度；待发占额可退回，发车后锁定。
4. **送达核减**：实际送达后核减油站缺口、释放该趟车辆额度，支持短卸，短卸差额回到待分配。
5. **超期回收**：超过一天未送达的占用自动回收为「已回收」，油量回到待分配。
